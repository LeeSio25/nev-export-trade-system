## v1.5 · 2026-10-31

### 修复

- **售后网点类型一编辑就被清空（会丢数据）**：列注释写作「销售/售后/充电」，被当成三个独立值；
  而库里实际存的是组合值（`销售/售后`、`销售/充电`）。下拉里一个都命中不了，用户一点保存就写回 NULL。
  现在注释改成显式清单「销售、售后、充电、销售/售后、销售/充电」，解析器优先按「、」切分
  （值本身允许带斜杠）；并加兜底：**库里已有的值若不在清单里，原样保留并提示**，任何表都不会再被静默清空。
- **两个状态字段的下拉缺合法值**：`customs.CustomsStatus` 缺「已申报」、`waybill.WaybillStatus` 缺「未发运」，
  CHECK 允许但下拉给不出，用户只能留空。已补齐，顺带补上 `carrier.CreditLevel` 的 A/B/C/D。
- **「未签收」漏掉状态为空的运单**：取反筛选拼的是 `<> '签收'`，NULL 不参与比较，
  新录运单不填状态就会从待办里凭空消失。改为 `<> '签收' OR IS NULL`。
- **认证预警口径不实**：页面说「20 个车型认证 180 天内到期」，其中 17 个其实早就过期；
  首页提醒列表用 90 天窗、卡片用 180 天窗，同一页面两个口径。
  现在统一 180 天窗，并拆出已过期 / 临期两个数字，文案改为「已过期或临期，其中 17 张已过期」。
- **SQL 演示台的只读拦截可被绕过**：原先只比对开头几个字符，`WITH x AS (...) DELETE FROM exportorder` 能通过。
  现在按语句类型白名单判断，并先剥掉注释与字符串字面量再判；
  同时挡掉 `INTO OUTFILE / DUMPFILE` 与加锁读（`FOR UPDATE` / `LOCK IN SHARE MODE`）。

### 变更

- 修正 4 个列的注释（`aftersales.ASType`、`customs.CustomsStatus`、`waybill.WaybillStatus`、`carrier.CreditLevel`），
  `sql/cnev_export_trade_db.sql` 已重新导出，并实测可完整导入（18 张表 / 22 外键 / 29 CHECK）。
- 报告同步：表3-8 运输方式补「空运」、表3-9 运单状态补「未发运」、报关单状态补「已申报」、
  表3-13 网点类型改为与库一致的写法。

### 验证

- 售后网点 A002 保存前后 `ASType` 均为「销售/售后」，编辑页下拉已正确选中该值
- 全库扫描：CHECK 允许但下拉给不出的字段 **0 个**；库中已有取值不在下拉里的 **0 个**
- 插入一条状态为 NULL 的运单：未签收卡片 5 → 6，点进去列表也是 6，删除后回到 5
- SQL 演示台 7 种写法（CTE+DELETE / 注释开头 / 括号包裹 / INTO OUTFILE / 字符串含关键字 / 普通查询 / CTE+SELECT）结果全部符合预期
- 端到端测试 **35 项通过**（新增 6 项：枚举覆盖 3 项、演示台绕过 3 项）

## v1.4 · 2026-10-31

### 修复

- **报告与系统口径不一致**：报告功能图 6.4 仍写「政策前后订单对比」，系统早已改为「政策生效后出口情况」
  （政策生效时间与订单时间窗不重合，前后对比恒为 0，留不住的结论不如不给）。报告已同步改名。
- **首页待办数字和列表对不上**：三张卡片点进去的筛选条件与统计口径不同（卡片算「在途+到港」，链接只筛「在途」；
  「未报关」点进去却是报关单表）。现在**数字与链接由同一份条件生成**，卡片算几条，列表就几条。
- **排序保留旧页码**：`url_with` 传 `page=None` 只是不写入，并没有删掉原参数，在第 2 页点排序会带着 `page=2` 跳过去，
  结果集变短后停在空页。现在 `None` 明确表示「删除该参数」。
- **订单合规提示不分目的国**：发往科威特的订单会把泰国、以色列的认证当成这单的合规要求。
  认证是按国家发布的（`certification.CountryCode`），现在只认目的国那几张；一张都没有时明确提示
  「尚未查到该国认证记录，其他国家认证不能替代」，而不是悄悄显示别国证书。
- **明文口令与密钥**：`config.py` 的数据库口令、`app.py` 的 `secret_key` 都写死在源码里。
  现在口令按「环境变量 `DB_PASSWORD` → `secrets_local.py` → 缺失即中文提示」取用，密钥同理，源码里不再出现任何口令。

### 新增

- 列表筛选支持三种更强表达，和首页待办共用同一套语义：
  `f_OrderStatus=在途,到港`（多值 IN）、`f_WaybillStatus=!签收`（取反）、`missing=customs`（只看没有对应报关单的订单）。
  多值与取反的筛选值会在下拉里补成可读选项（「在途 / 到港」「≠ 签收」），不会显示成「全部」。
- 新增 `secrets_local.example.py` 与 `.gitignore`；`.gitignore` 已排除 `secrets_local.py`，该文件不随包分发。

### 验证

- 首页四张待办卡片逐个点进去核对条数：5 / 1 / 5 / 20，与卡片数字完全一致
- 第 2 页排序链接已不含 `page=`；多值、取反、`missing` 三种筛选实测命中数与 SQL 手算一致
- 订单页按目的国核对：科威特单（无本国认证）→ 风险提示；德国单 → 均在有效期；泰国单 → 只剩泰国认证
- 端到端测试 29 项通过

## v1.3 · 2026-10-30

### 新增

- **外键字段可以边打字边筛**：企业、国家、经销商这类字段原来只能在几十个选项里翻，
  现在输入名称或代码即时过滤（后端 `GET /api/lookup/<表>?q=`），命中处高亮，键盘上下键 + 回车可选。
- **库里还没有的记录能当场补**：点字段右侧的 ＋ 弹出新增浮层，保存后新记录自动填回当前表单并选中，
  上级表单已填的内容一点不丢。这就是「万一有新的公司选不了」的解法。

### 变更

- 外键下拉只显示名称，编号以小字排在右侧；只有重名时才在名称后补编号。
- 浮层内的新增表单不再重复显示页面标题和「返回列表」按钮。

### 修复

- **外键下拉面板被卡片裁掉**：表单卡片 `overflow:hidden`，靠下几行点开下拉会被切一半。现改为可见，表单脚栏补圆角。
- **面板顶出窗口**：下方空间不足时自动向上翻转，上下都不足时压缩列表高度，保证「＋ 新增」始终点得到。
- **必填外键限制失效**：`required` 加在隐藏域上浏览器不校验，清空后能直接提交、再由数据库报错。现改为提交时拦截并定位提示。

### 验证

- 浏览器实测 15 项交互（筛选 / 点选 / 清空 / 必填拦截 / 浮层新增回填 / 表单取值）全部通过
- 端到端测试 29 项通过；18 张表的列表页、新增页与候选接口，8 张表的编辑页，全部正常

## v1.2 · 2026-10-30

### 修复

- **新增「质量事件」必然失败**：选择「是否召回」后提交报「字符串长度超出字段定义（1406）」。
  原因是该列注释写作 `是否召回Y/N`（无冒号），被按斜杠拆成了「是否召回Y」「N」两个选项，
  选择第一项即把 15 个字符写入 `char(1)`。现先识别以 `Y/N` 结尾的写法，正确输出 `Y` / `N`。
- **同类隐患加防御**：枚举选项若长度超过字段定义，不再按枚举渲染，退回普通输入框，避免再出现「怎么选都提交失败」。
- **数据字典「键」列标签重叠**：`PK`/`FK`/`NN` 三个标签在本列宽度不足时溢出，压在右侧说明文字上。
  现加宽该列、缩小标签并允许换行。
- **数据字典说明列溢出**：`exportmodel.ModelID` 这类长标识符在点号处无法断行，顶出卡片右边缘。现允许任意位置断行。

### 变更

- 日期字段提示文案补充为「格式 2026-10-30（年-月-日）」。
  输入框内的「yyyy/mm/日」由浏览器按语言环境生成，无法自定义，实际提交与存储均为 `YYYY-MM-DD`。

### 验证

- 实测新增一条质量事件：下拉选项为 `Y` / `N`，提交成功，数据入库正确
- 端到端测试 29 项全部通过；41 个路由（含 18 张表的新增表单）无异常

## v1.1 · 2026-10-30

### 修复

- **组名错误**：页面显示为「哈基米小组」，实际应为「黑科技小组」。已更正页头、页脚与说明文档中的全部出现位置。
- **说明字段显示不全**：字段定义表格中的注释被省略号截断且无悬浮提示；数据字典的说明列仅占 36% 宽度，长注释被挤成多行。现说明列支持换行显示全文，字段名与类型列补充悬浮提示。
- **导航图标缺失**：左侧「政策适用国家」的图标未在图标库中定义，渲染为空白。已补上。
- **表格滚动后第一列错乱**：表头层级（z-index 2）低于数据固定列（4），表格内部滚动时数据行盖住吸顶表头，最左两列出现空白。已重排层级，表头始终位于数据行之上。
- **导航分组全部展开**：分组展开状态写死在页面中，每次跳转后所有分组重新展开。现按分组记住展开/收起状态。
- **侧栏滚动位置重置**：跳转后侧栏回到顶部。现保留滚动位置；当前页面所在分组会自动展开。

### 同时修正（此前测试发现）

- 订单履约进度出现「签收日期早于到港日期」。原因为误用报关申报日充当签收日，现严格按实际推进环节取日期，预计到港不再当作已到港。
- 「政策生效前后订单对比」恒为 0。因政策生效时间与订单时间窗不重合，改为「政策生效后出口情况」，按生效至今累计统计。
- 首页合同金额末位被卡片边框裁切，改为万元显示并保留精确值悬浮提示。
- 订单详情的运单表列数过多导致撑破卡片，合并为「行程」单元格并固定列宽。

### 验证

- 端到端测试 29 项全部通过
- 全站 24 个路由无异常，18 张数据表访问正常
